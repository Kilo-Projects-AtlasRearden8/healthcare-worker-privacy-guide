# AI Privacy for Healthcare Workers

A beginner manual and static HTML site on AI privacy for healthcare workers:
what never to paste into chatbots, patient data basics, and safe habits.
Education only — never medical advice. Includes a printable checklist.

Credits: **Asdale Dynamics, LLC** — beginner-friendly AI education, books, and
guides. Founded by Dylan Asdale, registered nurse turned AI author, Indiana
(formed October 2026). Hub site: dylanasdale.github.io

## What's inside

- `docs/` — beginner manual in Markdown:
  - `patient-data-basics.md` — what patient data is and why it matters
  - `what-never-to-paste.md` — what never to paste into AI chatbots
  - `safe-habits.md` — practical, everyday safe habits
  - `disclaimer.md` — education only, never medical advice
  - `checklist.md` — printable one-page checklist
- `site/` — static HTML version of the manual, no build step needed:
  - `site/index.html` and one page per topic
  - `site/style.css` — warm, plain-English styling
  - `site/print.css` — print stylesheet for the checklist

## How to use

Read the Markdown in `docs/`, or open any `.html` file in `site/` directly in
your browser. No server, no install, no account required.
